# Launch drafts

Everything in this directory is draft copy, not evidence that a release or test
has happened. Do not publish a draft merely because the repository contains it.

## Publication gate

Before using any launch copy:

1. confirm the named version exists in GitHub Releases;
2. verify the signed/notarized DMG and clean Homebrew installation;
3. link a dated passing Telex/VNI live-input result for claims about Vietnamese
   composition or in-preedit completion;
4. replace benchmark and comparison claims with current reproducible evidence;
5. remove planned features and stale version numbers;
6. obtain explicit consent for every tester name, quote, or adopter reference.

Automated IME bridge tests are not equivalent to testing macOS Telex/VNI input
sources. Download counts are not verified users. Stars are not completed beta
tests. If a claim has no evidence link, weaken or remove it.
