# Herminal closed-beta call

## English

I'm looking for 5–10 macOS developers to test Herminal, an open-source native terminal built around two workflows: reliable Vietnamese Telex/VNI input and a local dashboard for Codex, Claude Code, and Aider sessions.

The useful test is not “does it open?” Please use it on one real repository for three days, then submit a privacy-safe report. I especially need people who use Vietnamese input, zsh/tmux, SSH, or multiple coding agents.

- macOS 14+, Apple Silicon
- local-first: no account, telemetry, or terminal-content upload
- signed/notarized build supplied when the release gate passes
- no request to star, endorse, or publish your identity

Repository and tester protocol: https://github.com/hoangperry/herminal — see `docs/BETA.md`.

## Tiếng Việt

Mình cần 5–10 developer macOS thử Herminal — terminal native mã nguồn mở tập trung vào hai việc: gõ Telex/VNI đáng tin cậy và theo dõi local các session Codex, Claude Code, Aider.

Bài test có giá trị không chỉ là “app mở được”. Hãy dùng Herminal với một repository thật trong khoảng ba ngày rồi gửi report đã loại bỏ dữ liệu riêng tư. Mình đặc biệt cần người dùng bộ gõ tiếng Việt, zsh/tmux, SSH hoặc chạy nhiều coding agent.

- macOS 14+, Apple Silicon
- local-first: không account, telemetry hay upload nội dung terminal
- cung cấp bản ký/notarized sau khi vượt release gate
- không yêu cầu star, testimonial hoặc công khai danh tính

Repo và quy trình test: https://github.com/hoangperry/herminal — xem `docs/BETA.md`.
